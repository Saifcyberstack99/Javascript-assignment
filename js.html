Variables

Think: Variable is like a box where you keep values. Like keeping books in a school bag!

VAR - Old Box

This one:

  • Can make two boxes with same name
  • Can change box value
  • Visible in whole class (function)
// Example:
var name = "Wahab";
var name = "Hammad"; // Works
name = "Saif"; // Value changed
Result:

LET - New Box

This one:

  • Can make ONLY ONE box with same name
  • Can change box value
  • Visible only in its room (block)
// Example:
let age = 20;
// let age = 21; // ERROR!
age = 21; // Value changed
Result:

CONST - Permanent Box

This one:

  • Can make ONLY ONE box with same name
  • CANNOT change box value
  • Must put value first time itself
// Example:
const birthday = "7 November";
// birthday = "26 January"; // ERROR!

// But can change inside object:
const student = { name: "Saif" };
student.age = 17; // Works

📊 Simple Comparison

What var let const
Can declare again? ✅ Yes ❌ No ❌ No
Can change value? ✅ Yes ✅ Yes ❌ No
Need value first time? ❌ No ❌ No ✅ Yes

💡 Real Life Examples

Phone Book Example:

// CONST - Will never change
const COUNTRY_CODE = "+91";

// LET - Can change
let mobileNumber = "9876543210";
mobileNumber = "9876543211"; // Number changed

// VAR - Old way (avoid)
var contactName = "Saif";
var contactName = "Kashan"; // Declared again - confusion!

📝 Simple Rules to Remember

  1. Use const when value won't change
  2. Use let when value will change
  3. Don't use var (it's old)
